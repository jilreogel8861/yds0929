직접 만들기 — 재료를 순서대로 눌러요
🧭 이렇게 해요
  1. 🧩 도형 모드: 아래에서 도형을 골라 물 위로 끌어다 놓거나, 도형을 고른 뒤 물을 눌러요. 고른 도형을 한 번 더 누르면 돌아가고, 놓은 도형을 누르면 사라져요.
  2. 🍢 규칙 모드: 규칙 카드 순서대로 재료를 꽂아요. 출발 판 옆 반짝이는 칸부터 이어서 놓고, 순서가 틀리면 재료가 튕겨 나와요. 맨 끝 재료를 누르면 뺄 수 있어요.
  3. 섬까지 길이 이어지면 ▶ 출발!을 눌러요. 규칙 모드에서는 친구가 재료 이름을 말하며 건너요.
전자칠판에서는 브라우저를 전체 화면(F11)으로 하면 더 크게 보여요.
